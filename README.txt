TEXAS NEW HOME REBATES — VERSION 2 (STATIC / VERCEL SAFE)

WHY THIS VERSION:
This project uses plain HTML, CSS and JavaScript. There is no npm install and no Next.js build step, which makes deployment on Vercel much simpler and avoids the build timeout from Version 1.

HOW TO REPLACE THE OLD GITHUB FILES:
1. In your GitHub repository, delete the old Version 1 project files.
2. Upload EVERYTHING INSIDE this folder to the ROOT of the repository.
3. You should see index.html, styles.css, script.js, communities, builders, rebates, register, faq, and how-it-works at the top level.
4. Commit changes.
5. Vercel should automatically redeploy.
6. In Vercel project settings, Framework Preset can be "Other".
7. Build Command should be left blank.
8. Output Directory should be left blank.
9. No environment variables are needed.

IMPORTANT:
The registration form is a demo and sends data nowhere yet.
Community, builder, rebate, branding, and legal details are placeholders until verified/finalized.
